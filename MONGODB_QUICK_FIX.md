# 🚨 MongoDB Connection Error - Quick Fix Guide

## Error: `querySrv ENOTFOUND`

This error means your MongoDB connection string is **invalid or contains placeholder values**.

---

## ⚡ Quick Fix (5 Minutes)

### Option 1: Interactive Setup (Recommended)

Run this command and follow the prompts:

```bash
npm run setup:mongodb
```

This wizard will:
- ✅ Guide you through MongoDB Atlas setup
- ✅ Help you create database user
- ✅ Generate correct connection string
- ✅ Update your .env file automatically
- ✅ Test the connection

### Option 2: Manual Setup

#### Step 1: Open MongoDB Atlas

Go to: https://cloud.mongodb.com/

#### Step 2: Get Your Connection String

1. Click **"Connect"** on your cluster
2. Choose **"Connect your application"**
3. Copy the connection string

#### Step 3: Update .env File

Open your `.env` file and replace this line:

```env
MONGODB_URI=mongodb+srv://username:password@cluster0.xxxxx.mongodb.net/ai-interview-prep?retryWrites=true&w=majority
```

With your actual connection string:

```env
MONGODB_URI=mongodb+srv://YOUR_USERNAME:YOUR_PASSWORD@YOUR_CLUSTER.mongodb.net/ai-interview-prep?retryWrites=true&w=majority
```

**Example:**
```env
MONGODB_URI=mongodb+srv://aiuser:MySecurePass123@cluster0.abc123.mongodb.net/ai-interview-prep?retryWrites=true&w=majority
```

#### Step 4: URL Encode Special Characters

If your password has special characters like `@`, `#`, `$`, etc., encode them:

```bash
node -e "console.log(encodeURIComponent('YourPassword'))"
```

**Example:**
- Password: `MyP@ss#123`
- Encoded: `MyP%40ss%23123`

#### Step 5: Test Connection

```bash
npm run test:mongodb
```

## 🔍 Common Issues

### Issue 1: Placeholder Values

**Error:** Connection string still has `username:password` or `cluster0.xxxxx`

**Fix:** Replace with your actual MongoDB Atlas credentials

### Issue 2: Special Characters Not Encoded

**Error:** `Authentication failed`

**Fix:** URL encode special characters in password:
```bash
node -e "console.log(encodeURIComponent('YourPassword'))"
```

### Issue 3: Network Access Not Configured

**Error:** `ECONNREFUSED` or timeout

**Fix:** 
1. Go to MongoDB Atlas → Network Access
2. Add IP Address: `0.0.0.0/0` (Allow from anywhere)
3. Wait 1-2 minutes

### Issue 4: Database User Doesn't Exist

**Error:** `Authentication failed` or `bad auth`

**Fix:**
1. Go to MongoDB Atlas → Database Access
2. Create new database user
3. Set privileges to "Read and write to any database"
4. Use autogenerated password
